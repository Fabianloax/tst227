# 2K27 Prom

Flask registration, payment approval, entrance-code, and Gmail notification app.

## Local run

Set the Gmail environment variables, then run `python app.py`.

## Cloud deployment

The included `render.yaml` deploys the app to Render. Add these values in the
Render dashboard, not to this repository:

- `DATABASE_URL` — Supabase Postgres connection string
- `GMAIL_SMTP_USERNAME`
- `GMAIL_SMTP_APP_PASSWORD`
- `GMAIL_SENDER_NAME`

`FLASK_SECRET_KEY` is generated by Render. Local development uses SQLite;
production uses Postgres when `DATABASE_URL` is present.
